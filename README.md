🚀 **Sign Language Gesture Recognition using CNN + LSTM**

I'm excited to share my latest Deep Learning project—a **Real-Time Sign Language Gesture Recognition System** that recognizes hand gestures using **MediaPipe**, **CNN + BiLSTM**, and a user-friendly **Tkinter GUI**.

### 🎯 Project Objective

The goal of this project is to recognize sign language gestures in real time using hand landmark sequences, enabling more natural human-computer interaction and supporting communication through AI-powered gesture recognition.

### 🔹 Key Features

* Real-time hand tracking with **MediaPipe**
* **CNN + Bidirectional LSTM** model for gesture recognition
* Data collection using webcam
* Landmark preprocessing and data augmentation
* Training pipeline with checkpointing and early stopping
* Interactive **Tkinter GUI** for live prediction
* Confidence scores and sentence-building feature
* Automated testing and modular project structure

### 🛠 Tech Stack

**Python • TensorFlow/Keras • OpenCV • MediaPipe • NumPy • Tkinter • Matplotlib • PyTest**

### 📊 Highlights

✅ End-to-end Deep Learning pipeline
✅ Real-time gesture recognition using webcam
✅ Configurable CNN + BiLSTM architecture
✅ Complete data collection, training, and inference workflow
✅ Well-structured, scalable, and documented codebase

This project helped me strengthen my skills in **Computer Vision**, **Deep Learning**, **Sequence Modeling**, **GUI Development**, and building complete AI applications from data collection to deployment.
